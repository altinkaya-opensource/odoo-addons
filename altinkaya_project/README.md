# Altinkaya Project

Custom extensions for OCA project module tailored for Altinkaya Enclosures.

## Features

- Automatically inherits `display_project_id` from parent task when creating subtasks
- Automatically inherits tags from parent task when creating subtasks

## Installation

1. Add this module to your addons path
2. Update the app list
3. Install the module from Apps menu

## Configuration

No additional configuration required.
