Custom Charts & KPIs

Real-Time Data

Effortlessly pull data from any Odoo module, such as Sales, Inventory, CRM, Accounting, or HR, to create meaningful visualizations tailored to your needs.

Real-Time Data with Advanced Aggregations

The Dynamic Dashboard App not only pulls live data from Odoo models like Sales, Inventory, CRM, and more, but also empowers you to analyze this data with advanced aggregation capabilities.

Enhanced Data Control: Sorting and Data Limits for Precise Insights

Whether you need to sort sales by highest revenue, customers by name, or inventory by stock level, this feature allows you to prioritize the data that matters most.

Click-to-Filter Functionality

When you click on any grouped segment in the chart (e.g., a specific customer in a sales chart), the dashboard dynamically updates to display only the data related to that group.

Create Dynamic Chart

Simply select the chart type (e.g., bar, line, pie), choose the data model, and configure your group-by and aggregate functions to summarize your data.

Chart Preview

Sales Orders by Customer: Visualize your sales performance grouped by partner_id (customers), making it easy to identify top buyers and analyze customer trends. Accounts by Type: View your financial data grouped by type, providing a clear breakdown of account categories like income, expenses, or liabilities.

Create Kpi Card

Designing impactful KPI cards is simple and intuitive. Assign a custom card name, choose the data model, and configure the aggregate function (e.g., sum, count, average) to calculate your key metrics. Customize further with options to define the card color, size, and sequence for an organized and visually appealing layout.

Kpi Preview

Clear and Concise Information: Display aggregated values like total sales, customer count, or average order value in an easy-to-read format, making it simple to track performance at a glance.

Interactive Chart Filtering: Dive Deeper with a Click

When a chart is created, each portion represents a grouped data segment. Clicking on a specific segment dynamically filters the group-by values and displays them in a dedicated wizard screen. This seamless interaction allows you to instantly drill down into the details of any group, providing a focused view of the underlying data without navigating away from the dashboard.

Advanced Chart Features: Full Control Over Data Display

Sort by Ascending/Descending: Arrange data in your desired order to focus on key insights, such as highest sales or most recent entries. Custom Domains: Apply custom filters by writing domains to refine data and display only what’s relevant to your analysis. Set Data Limits: Control the number of records shown in your chart to avoid clutter and highlight the most important metrics, such as the top 10 customers or latest transactions.

Flexible Menu Configuration: Tailor Your Dashboard Placement and Access

Add Menus Anywhere: Create a new dashboard menu and link it to any existing menu in Odoo. If no parent menu is selected, the dashboard is automatically added under the Samurai Dashboard menu for easy access. Group Access Control: Assign specific user groups to the dashboard menu, ensuring that only authorized users can view and interact with it. This enhances data security and relevance for different roles. Dashboard Column Layout: Customize the dashboard layout by defining the number of columns per row (e.g., two or three). This allows you to control how charts and KPI cards are displayed, ensuring a clean and organized interface tailored to your preferences.
