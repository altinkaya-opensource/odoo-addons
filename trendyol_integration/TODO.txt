Trendyol Integration - TODO
============================

1. Invoice Sending - Nightly Batch Instead of action_post
   - Current: invoice link is sent immediately on action_post override.
     Problem: user may post then cancel the invoice, sending a wrong link.
   - Solution: remove action_post override, add a nightly cron that finds
     posted invoices linked to Trendyol orders where invoice_link_sent=False
     and sends them in batch.
   - Also send "Invoiced" status via updatePackage alongside the invoice link.

2. Q&A Model - Customer Questions
   - API endpoints already implemented in trendyol_request.py:
     get_questions() and answer_question().
   - Create trendyol.question model (mail.thread) with fields:
     question_id, product_binding_id, customer_name, question_text,
     answer_text, status (waiting/answered/rejected), question_date.
   - Add cron to poll questions periodically.
   - Add user_ids (Many2many res.users) field on trendyol.backend to define
     who gets notified on new questions.
   - Post mail.message notification to those users when new question arrives.
   - Add answer action button + view.

3. Shipping Labels
   - API provides createCommonLabel / getCommonLabel endpoints.
   - Implement label request and download on stock.picking for Trendyol orders.
   - Add button on picking form to fetch and print the label.

4. Financial Statements
   - API provides settlements, otherfinancials, and cargo invoice endpoints.
   - Create trendyol.settlement model to store financial transactions.
   - Add cron to import settlements periodically (max 15-day date range).
   - Use for reconciling Trendyol marketplace payments against Odoo journals.

5. Claim Rejection
   - API provides createClaimIssue for rejecting returns with reason.
   - Add action_reject_claim() with reason selection wizard.
   - Fetch rejection reasons from getClaimsIssueReasons endpoint.

6. Webhook Management from UI
   - API client has create/get/delete webhook methods but no UI buttons.
   - Add action buttons on backend form to create, list, and delete webhooks
     directly from Odoo instead of manual Trendyol panel configuration.

7. Multi-Region Address Support
   - Currently defaults country to TR.

   - Handle countryCode properly from order address data.
